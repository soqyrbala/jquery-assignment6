## Description
A multi-page static website demonstrating jQuery 3.7.1 (loaded from the official CDN). Every page has a navbar linking to all parts of the assignment.

| Page | Tasks |
|------|-------|
| `index.html` | Task 0 (setup, `$(document).ready`), Task 1 (selectors, `.text()`, `.html()`, `.css()`) |
| `effects.html` | Task 2 (`hide/show/toggle`), Task 3 (`fadeIn/fadeOut/fadeToggle`), Task 4 (`slideUp/slideDown/slideToggle`) |
| `dom.html` | Task 5 (`append/prepend/remove`), Task 6 (`.attr()` for `src` and `href`), Task 7 (live form with `.val()` and `.text()`) |
| `animations.html` | Task 8 (`.animate()`), Task 9 (sequential animation), Task 10 (combined animation) |
| `project.html` | Task 11 (mini project: Image Gallery) |

## How to run
1. Clone or download the repository.
2. Open `index.html` in a browser (internet is needed for the jQuery CDN).
3. Open the console (F12) on the first page to see `jQuery is ready!`.

## Deploy to GitHub Pages
1. Push all files to a GitHub repository.
2. Settings -> Pages -> Source: `main` branch, `/ (root)` -> Save.
3. Put the resulting link in the "Live demo" line above.
